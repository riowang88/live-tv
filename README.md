# 电视直播

安卓电视上看 CCTV 和卫视直播的小工具。打开就是画面，没有首页、推荐和登录弹窗。

安装包 33 KB，只申请联网权限。电视和安卓手机都能用。本仓库只提供安装包，不含源码。

**[下载最新版](../../releases/latest)**

## 选哪个包

| 包 | 大小 | 适合 | 状态 |
|---|---|---|---|
| `live-tv-v1.2.apk` | 33 KB | 系统网页内核 Chrome 60 以上，一般是安卓 9 及以上 | 主力版本 |
| [`live-tv-v1.2-android5.apk`](../../releases/tag/v1.2-old-android) | 82 MB | 内核太旧的安卓 5.0 到 8.1 | **未经任何真机测试** |
| [`live-tv-v1.2-android4.1.apk`](../../releases/tag/v1.2-old-android) | 63 MB | 安卓 4.1 到 4.4 | **未经任何真机测试** |

两个大包自带 Firefox 内核（GeckoView），只支持 32 位 ARM（armeabi-v7a），部分 64 位设备也能运行。能装上不代表能播放：老设备的解码能力和内存都可能不够，1GB 内存的设备尤其困难。优先用小包，小包提示内核太旧时再试大包。

## 安装

1. 从 Releases 下载最新的 `live-tv-v*.apk`，拷到 U 盘，插到电视上。手机直接下载安装即可。
2. 用电视的文件管理器打开它。如果提示未知来源，到设置里允许安装。
3. 在桌面或应用列表打开“电视直播”。

已打开 ADB 的电视也可以这样安装：

```bash
adb connect 电视IP:5555
adb install -r live-tv-v1.2.apk
```

## 遥控器

| 按键 | 作用 |
|---|---|
| OK | 打开频道列表，每个台下面显示正在播的节目 |
| ▲ ▼ | 换台；列表打开时是移动选择 |
| ▶ | 切换清晰度：1080P、720P、540P |
| OK（列表中） | 切到选中的台 |
| 返回 | 关闭列表；连按两次退出 |

手机上：

| 操作 | 作用 |
|---|---|
| 点屏幕 | 打开或关闭频道列表 |
| 上下滑 | 换台（上滑下一个台） |
| 点列表里的台 | 切过去 |
| 点列表顶部的清晰度 | 切换 1080P、720P、540P |

手机固定横屏播放。下次打开会回到上次看的台和上次选的清晰度。切到后台会暂停，回来继续播。走备用线路时固定 720P，不能切换。

加载和换台时，屏幕上会显示当前网速，可以用来判断是网络慢还是在等页面。这个数字是整个 App 的下载速度，包含网页和节目单，不只是视频。

## 使用条件

能不能用，看的是系统网页内核（Android System WebView）的版本，不是安卓版本。

- **内核低于 Chrome 60：不支持。** 官方网页跑不起来，App 打开会直接提示，不会黑屏。
- **安卓 9 及以上：建议使用。** 系统自带内核一般够新。
- **安卓 5 到 8.1：看内核。** 出厂内核大多太旧，升级过内核才可能能用，很多电视和盒子升级不了。可以试 `android5` 大包。
- **安卓 4.1 到 4.4：** 小包装不上，只能试 `android4.1` 大包。
- **安卓 4.0 及更低：不支持。**

内核版本的要求来自对官方网页脚本的检查；各安卓版本的对应关系是一般情况，没有逐一实测。

## 实际表现

在一台雷鸟电视上实测（Android 11，WebView 83，armeabi-v7a）：

- 画面 1080P，有声音，共 51 个台。
- 冷启动约 18–24 秒，换台约 9–14 秒。速度取决于网络和设备性能。
- 央视频 20 秒没出画面时，CCTV 频道自动切到央视网备用源（720P）。卫视没有备用源。

其他电视和手机没有实机测试过，不保证能播。以上实测都是 33 KB 小包，两个大包没有实测。
