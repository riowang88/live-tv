# 电视直播

安卓电视上看 CCTV 和卫视直播的小工具。打开就是画面，没有首页、推荐和登录弹窗。

安装包 33 KB，只申请联网权限。电视和安卓手机都能用。本仓库只提供安装包，不含源码。

**[下载最新版](../../releases/latest)**

## 安装

1. 从 Releases 下载最新的 `live-tv-v*.apk`，拷到 U 盘，插到电视上。手机直接下载安装即可。
2. 用电视的文件管理器打开它。如果提示未知来源，到设置里允许安装。
3. 在桌面或应用列表打开“电视直播”。

已打开 ADB 的电视也可以这样安装：

```bash
adb connect 电视IP:5555
adb install -r live-tv-v1.1.apk
```

## 遥控器

| 按键 | 作用 |
|---|---|
| OK | 打开频道列表，每个台下面显示正在播的节目 |
| ▲ ▼ | 换台；列表打开时是移动选择 |
| OK（列表中） | 切到选中的台 |
| 返回 | 关闭列表；连按两次退出 |

手机上：

| 操作 | 作用 |
|---|---|
| 点屏幕 | 打开或关闭频道列表 |
| 上下滑 | 换台（上滑下一个台） |
| 点列表里的台 | 切过去 |

手机固定横屏播放。下次打开会回到上次看的台。切到后台会暂停，回来继续播。

加载和换台时，屏幕上会显示当前网速，可以用来判断是网络慢还是在等页面。这个数字是整个 App 的下载速度，包含网页和节目单，不只是视频。

## 使用条件

- 安卓 5.0 及以上，能联网。手机需要屏幕能横过来。
- 系统网页内核（Android System WebView）建议 Chrome 60 以上。App 启动时会检查，太旧会直接提示。

## 实际表现

在一台雷鸟电视上实测（Android 11，WebView 83，armeabi-v7a）：

- 画面 1080P，有声音，共 51 个台。
- 冷启动约 18–24 秒，换台约 9–14 秒。速度取决于网络和设备性能。
- 央视频 20 秒没出画面时，CCTV 频道自动切到央视网备用源（720P）。卫视没有备用源。

其他电视和手机没有实机测试过，不保证能播。
